# Test data

`ff6_prueba.mavlink`: a flight plan saved by FreeFlight 6 (iPhone) for an Anafi
on firmware 1.8.2, unchanged except that the waypoints were moved 0.45° south
and 0.5° west to a made-up location. FreeFlight wrote it next to its own
`savedPlan.json` and `screenshot.png` in the plan's folder on the phone. The
camera settings in the app (GPS lapse) were not written into the file: it always
records video.
